# Port Scanner - Python Cybersecurity Tool

A simple and fast port scanner built with Python to detect open ports on a target IP address. This project is made for learning network security and socket programming.

### Features
- Scans 1 to 1024 common ports
- Detects open ports quickly
- Handles invalid IP and network errors
- Beginner-friendly code for cybersecurity learning

### Tech Stack
- Python 3
- Socket Library

### How to Run
1. Clone the repo
2. Run the script:
```bash
python scanner.py
